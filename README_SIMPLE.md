# AMPml - 抗菌肽预测软件

基于机器学习的抗菌肽(AMP)预测工具，提供现代化的Web界面。

## 📱 **软件使用方法**

### 🚀 **启动软件**

1. **打开终端/命令提示符**
2. **进入软件目录**：
   ```bash
   cd AMPml-main
   ```
3. **启动程序**：
   ```bash
   python run_gui.py
   ```
4. **在浏览器中访问**：通常是 `http://localhost:8080`

### 📊 **模型训练步骤**

#### **第1步：上传训练数据**
- **正样本文件**：包含AMP序列的FASTA文件
- **负样本文件**：包含非AMP序列的FASTA文件
- **特征删除文件**（可选）：要排除的特征列表

#### **第2步：选择参数**
- **特征表示方法**：
  - `AAC`：氨基酸组成（20个特征）
  - `CTDD`：组成-转换-分布描述符（40个特征）
  - `PAAC`：伪氨基酸组成（29个特征）

- **机器学习方法**：
  - `RF`：随机森林（推荐）
  - `SVM`：支持向量机
  - `GT`：梯度提升
  - `Bayes`：朴素贝叶斯

#### **第3步：设置训练参数**
- **随机种子**：默认2020（保证结果可重现）
- **树的数量**：默认100（仅RF方法）
- **特征重要性分析**：可选勾选

#### **第4步：开始训练**
点击"开始训练"按钮，等待训练完成

### 🔮 **序列预测步骤**

#### **第1步：上传预测文件**
- 上传包含待预测序列的FASTA文件

#### **第2步：选择模型**
- 选择之前训练好的模型文件（.model格式）

#### **第3步：开始预测**
点击"开始预测"按钮

### 📁 **结果文件说明**

训练和预测完成后，所有结果文件保存在 `result/` 目录下：

#### **训练结果文件**：
- `AMPpred_[方法].model`：训练好的机器学习模型
- `model_[算法]_score.txt`：模型评估指标
- `feature_importances.txt`：特征重要性数据（如果勾选）
- `ROC_[算法].png`：ROC曲线图
- `feature_importances.png`：特征重要性图（如果勾选）

#### **预测结果文件**：
- `AMPpred.tsv`：预测结果表格，包含：
  - `seq_id`：序列ID
  - `probability_nonAMP`：非AMP概率
  - `probability_AMP`：AMP概率  
  - `predicted`：预测结果（AMP/非AMP）

### 💡 **使用建议**

1. **数据准备**：
   - 确保FASTA文件格式正确
   - 正负样本数量尽量平衡
   - 序列长度建议在5-50个氨基酸之间

2. **参数选择**：
   - 初次使用推荐：`AAC` + `RF`
   - 数据量大时推荐：`PAAC` + `RF`
   - 需要解释性时勾选"特征重要性分析"

3. **结果解读**：
   - AUC > 0.8：模型性能良好
   - F1分数 > 0.8：预测准确性较高
   - 查看混淆矩阵了解具体分类效果

### ❗ **常见问题**

- **文件上传失败**：检查文件格式是否为FASTA
- **训练时间过长**：减少树的数量或使用较简单的算法
- **预测结果不准确**：尝试不同的特征表示方法或增加训练数据
